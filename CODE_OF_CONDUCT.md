# Code of conduct

We welcome contributors of all backgrounds and experience levels. Be respectful, explain technical disagreements with evidence, credit others' work and help make the project accessible.

Harassment, threats, discrimination, sexualized conduct, doxxing and sharing private documents or credentials are unacceptable. Do not pressure anyone to disclose a PDF to reproduce a problem; create a synthetic fixture instead.

The repository owner maintains this policy and may edit/remove harmful content, restrict participation or block accounts. Apply responses proportionately and protect reporters' privacy. For public conduct problems, use GitHub's report-content tools; contact the repository owner through the contact methods available on their GitHub profile for confidential concerns. Do not disclose someone else's private information in an issue. GitHub's own community rules also apply.
